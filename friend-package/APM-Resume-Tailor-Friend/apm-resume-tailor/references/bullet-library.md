# Approved Bullet Library

Use this optional file as wording memory, not evidence. A new user can start with only a current résumé and complete JD.

```markdown
## Experience: <company or organization>

### Project: <project or workstream>

| Tailor Focus | Approved Bullet |
|---|---|
| <JD capability or recruiter-recognizable focus> | <final human-approved résumé bullet> |
```

Before drafting, search by Experience, Project, and Tailor Focus. Revalidate every claim against the current résumé or verified evidence; a library row never proves a fact.

After human feedback is resolved and PDF plus ATS/layout QA pass, save only final, human-approved, résumé-grade, materially distinct bullets. Skip keyword-only, punctuation, grammar, bolding, and light-synonym variants. Never delete unrelated entries.
